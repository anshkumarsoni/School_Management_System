CSV / Excel Bulk Import Guidelines

  • Files must be formatted as standard comma-separated values (.csv) encoded in UTF-8.
  • Column names are flexible and case-insensitive (e.g. ROLL_NUMBER, Roll Number, or roll_number are accepted).
  • Duplicate Key Safety: If a record with the same Roll Number or Teacher ID already exists, its data will be updated automatically via ON DUPLICATE KEY UPDATE.
  • For best results, download our ready-made starter templates from the Starter Templates tab.
